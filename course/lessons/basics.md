# 單元一：基礎語法

> **這個單元要解決的問題**：很多人寫 Python 寫了一陣子，還是會遇到「我明明只改了 b，為什麼 a 也變了？」「為什麼 0.1 + 0.2 不等於 0.3？」「為什麼 round(2.5) 是 2？」這類怪事。
> 這些都不是 Python 的 bug，而是你對「變數到底是什麼」「數字在電腦裡怎麼存」還有誤解。這個單元把地基打穩，後面五個單元都會用到。

**讀完你會知道：**

1. 變數其實是「標籤」，不是「盒子」——以及這為什麼重要
2. 哪些東西可以改（可變）、哪些不能改（不可變）
3. `is` 和 `==` 差在哪，什麼時候該用哪個
4. 整數、浮點數、`Decimal` 各自的能力和陷阱
5. 字串的切片、常用方法和格式化輸出
6. 怎麼讀取輸入資料（做練習題一定會用到）

## 1. 變數是「標籤」，不是「盒子」

### 1.1 先破除一個常見的誤解

很多教材會說「變數是一個盒子，裡面裝著值」。這個比喻在 C 語言裡大致成立，但在 Python 裡**是錯的**，而且會讓你之後踩很多坑。

在 Python 裡比較正確的想法是：

- **物件 (object)** 是實際存在記憶體裡的東西，例如數字 `5`、字串 `"hello"`、一個串列 `[1, 2, 3]`。
- **變數（正式名稱叫「名稱 name」）** 只是一張**貼在物件上的標籤**。

所以 `a = [1, 2, 3]` 的意思不是「把 [1, 2, 3] 放進盒子 a」，而是：

1. 先在記憶體裡建立一個串列物件 `[1, 2, 3]`
2. 再把標籤 `a` 貼到這個物件上

接著 `b = a` 的意思是「把標籤 `b` **也貼到同一個物件上**」，而**不是**複製一份。

```text
  a ──┐
      ├──►  [1, 2, 3]   ← 只有一個串列物件
  b ──┘
```

用程式驗證看看（可以直接按「▶ 執行」，也可以修改後再執行）：

```python
a = [1, 2, 3]
b = a            # b 貼到「同一個」串列上
b.append(4)      # 透過 b 修改這個串列
print("a =", a)  # a 也看到了 4，因為根本是同一個東西
print("b =", b)
print("a 和 b 是同一個物件嗎？", a is b)
print("id(a) =", id(a), " id(b) =", id(b))   # id() 可以看到物件的「身分證號碼」
```

> 💡 **白話說**：`b = a` 不是「影印一份給 b」，而是「讓 b 也指向 a 指著的那個東西」。就像兩個人手上拿著同一間房子的地址，其中一個人去把房子漆成紅色，另一個人去看時當然也是紅色的。

### 1.2 那為什麼數字好像不會這樣？

```python
x = 10
y = x       # y 和 x 貼在同一個整數物件 10 上
y = y + 1   # 建立「新的」整數物件 11，再把 y 這張標籤撕下來，貼到 11 上
print(x, y) # 10 11 ← x 完全沒受影響
```

關鍵在於：**整數是不可變的 (immutable)**。`y + 1` 沒有辦法把 `10` 這個物件「改成」11，它只能做出一個**新的** 11，然後把 `y` 重新貼過去。`x` 還是貼在原本的 10 上，所以不受影響。

而串列是**可變的 (mutable)**，`append` 是直接修改那個串列物件本身，所有貼在它上面的標籤都會看到變化。

### 1.3 每個物件的三個基本屬性

| 屬性 | 怎麼查 | 會不會變 | 白話解釋 |
|---|---|---|---|
| 身分 (identity) | `id(obj)` | 永遠不變 | 這個物件的「身分證號碼」 |
| 型別 (type) | `type(obj)` | 永遠不變 | 它是什麼「種類」的東西：整數？字串？ |
| 值 (value) | 直接看 | 可變物件可以改，不可變物件不行 | 它裡面裝的內容 |

```python
s = "hello"
print(id(s), type(s), s)
n = 42
print(id(n), type(n), n)
print(type(3.14), type(True), type(None), type([1]), type((1,)), type({"a": 1}), type({1}))
```

### 1.4 可變 vs 不可變：完整清單

| 不可變 (immutable)：內容建立後不能改 | 可變 (mutable)：可以原地修改 |
|---|---|
| `int` 整數、`float` 浮點數、`bool` 布林、`complex` 複數 | `list` 串列 |
| `str` 字串 | `dict` 字典 |
| `tuple` 元組 | `set` 集合 |
| `frozenset` 凍結集合、`bytes` 位元組 | `bytearray`、大部分你自己寫的類別 |
| `None` | |

**為什麼要在意這個？** 這個區分會在很多地方決定程式的行為：

1. **只有不可變（更精確地說是「可雜湊」）的東西才能當字典的 key、放進集合**。因為如果 key 可以被偷偷改掉，字典就找不到它了。
2. **函式的預設參數**用可變物件會出大問題（單元四會詳細說明）。
3. **多個變數共用同一個物件**時，可變物件會「牽一髮動全身」。

```python
s = "hello"
try:
    s[0] = "H"            # 字串不可變，不能改其中一個字元
except TypeError as e:
    print("TypeError:", e)

s = "H" + s[1:]           # 只能做出一個新字串，再把 s 重新貼過去
print(s)

t = (1, 2, 3)
try:
    t[0] = 100            # tuple 也不可變
except TypeError as e:
    print("TypeError:", e)
```

### ✍️ 自我檢查

下面這段程式印出什麼？先想好答案再執行。

```python
a = [1, 2]
b = a
a = a + [3]    # 注意：這裡是 a = a + ...，不是 a.append(3)
print(a, b)
```

<details><summary>看解答</summary>

印出 `[1, 2, 3] [1, 2]`。`a + [3]` 會建立一個**新的**串列，然後把 `a` 這張標籤貼到新串列上；`b` 還留在舊的串列。如果改成 `a.append(3)` 或 `a += [3]`，兩者都會變成 `[1, 2, 3]`，因為它們是**原地修改**。

</details>

## 2. `is` 和 `==`：比「是不是同一個」還是比「長得一不一樣」

- `==` 問的是：**兩個東西的值相等嗎？**（像在問「這兩張鈔票面額一樣嗎？」）
- `is` 問的是：**兩個名稱指的是同一個物件嗎？**（像在問「這兩張是同一張鈔票嗎？」）

```python
a = [1, 2, 3]
b = [1, 2, 3]       # 另外做了一個內容一樣的串列
c = a               # c 貼在 a 同一個物件上

print(a == b)       # True：內容一樣
print(a is b)       # False：是兩個不同的串列
print(a is c)       # True：同一個
```

### 2.1 為什麼不能用 `is` 比較數字和字串？

```python
x = 256
y = 256
print(x is y)        # 在 CPython 中通常是 True

x = int("1000")
y = int("1000")
print(x is y)        # 通常是 False！
print(x == y)        # True，這才是你真正想問的
```

CPython（最常用的 Python 實作）為了省記憶體，會預先建立 -5 到 256 這些常用的小整數，大家共用。但這是**實作細節**，換一個數字、換一個 Python 版本結果就可能不同。用 `is` 比較數字等於在依賴運氣。

> ✅ **規則**：
> - 比較「值」→ 一律用 `==`
> - 只有和 `None`、`True`、`False` 這種「全世界只有一個」的物件（稱為單例 singleton）比較時，才用 `is`，例如 `if x is None:`

## 3. 數字：看似簡單，其實暗藏陷阱

### 3.1 整數：沒有上限（但轉字串有限制）

在 C 或 Java 裡，`int` 有固定大小（例如 32 位元最大約 21 億），超過就會「溢位」變成負數。Python 的整數**會自動長大**，只要記憶體夠，多大都行：

```python
print(2 ** 100)
print(2 ** 1000 % 1000007)
big = 3 ** 5000
print("3 的 5000 次方有", len(str(big)), "位數")
```

**但是**，從 Python 3.11 開始，把「超過 4300 位數」的字串轉成整數（或反過來）會被擋下來。原因是這種轉換的運算時間是位數的平方，有人可以故意丟一個超長數字讓伺服器當機（一種阻斷服務攻擊）。

```python
import sys
print("目前的上限：", sys.get_int_max_str_digits())
try:
    int("9" * 5000)
except ValueError as e:
    print("ValueError:", e)

sys.set_int_max_str_digits(0)     # 0 代表解除限制（只在你確定資料安全時才這樣做）
print(len(str(int("9" * 5000))))
sys.set_int_max_str_digits(4300)  # 改回預設值
```

> 💡 **練習題會考**：題目給你一個 10 萬位數的數字，直接 `int(input())` 會出錯。另一個做法是「根本不轉成整數，直接當字串處理每個字元」。

### 3.2 除法家族：`/`、`//`、`%`、`divmod`

| 運算 | 意思 | `7 ? 2` | `-7 ? 2` |
|---|---|---|---|
| `/` | 真除法，結果**一定是 float** | `3.5` | `-3.5` |
| `//` | 地板除法：**往負無限大**取整 | `3` | **`-4`** |
| `%` | 取餘數，**正負號跟著除數** | `1` | **`1`** |
| `divmod(a, b)` | 一次拿到 `(a // b, a % b)` | `(3, 1)` | `(-4, 1)` |

最容易出錯的是**負數**。很多人以為 `-7 // 2` 是 `-3`（直接把小數點砍掉），但 Python 是「往下」取整，`-3.5` 往下是 `-4`。

```python
print(-7 // 2, -7 % 2)     # -4 1
print(int(-7 / 2))         # -3 ← 這才是「把小數砍掉」(往 0 取整)
print(7 // -2, 7 % -2)     # -4 -1 ← 除數是負的，餘數也是負的

# Python 保證這個等式永遠成立：
for a, b in [(7, 2), (-7, 2), (7, -2), (-7, -2)]:
    q, r = divmod(a, b)
    print(f"{a} = {b} × {q} + {r}", a == b * q + r)
```

**為什麼要設計成這樣？** 因為「餘數永遠和除數同號」在很多情境很好用。例如算星期幾：今天星期三（3），往回推 10 天是星期幾？`(3 - 10) % 7 = 0`，星期日。如果餘數可能是負的，你還得自己再處理一次。

```python
weekday = ["日", "一", "二", "三", "四", "五", "六"]
today = 3
for delta in [-10, -1, 0, 5, 100]:
    print(f"{delta:+} 天後是星期{weekday[(today + delta) % 7]}")
```

> ⚠️ **陷阱**：把秒數換成「分:秒」時，如果秒數是負的，`divmod(-1, 60)` 會得到 `(-1, 59)`，也就是「-1 分 59 秒」，不是你要的「-0 分 1 秒」。正確做法是**先取絕對值再算，最後補上負號**。

### 3.3 浮點數：電腦算不準小數？

```python
print(0.1 + 0.2)            # 0.30000000000000004
print(0.1 + 0.2 == 0.3)     # False
```

**為什麼？** 電腦用二進位（只有 0 和 1）存數字。就像十進位沒辦法精確寫出 1/3（0.3333…永遠寫不完），二進位也沒辦法精確寫出 0.1（在二進位是無限循環小數）。所以電腦存的其實是「最接近 0.1 的那個二進位數字」，有一點點誤差。誤差加起來，就不等於 0.3 了。

```python
print(f"{0.1:.25f}")        # 看看 0.1 實際上存了什麼
print(f"{0.3:.25f}")
print(f"{0.1 + 0.2:.25f}")
```

**怎麼辦？**

| 需求 | 做法 |
|---|---|
| 比較兩個浮點數是否「夠接近」 | `math.isclose(a, b)` |
| 金額等需要**精確十進位**的計算 | `decimal.Decimal`，而且**一定要用字串建立** |
| 需要精確分數（如 1/3） | `fractions.Fraction` |

```python
import math
from decimal import Decimal
from fractions import Fraction

print(math.isclose(0.1 + 0.2, 0.3))           # True
print(Decimal("0.1") + Decimal("0.2"))         # 0.3，精確
print(Decimal(0.1))                            # ⚠️ 從 float 建立 → 把誤差一起帶進來了
print(Fraction(1, 3) + Fraction(1, 6))         # 1/2
```

### 3.4 `round()` 的兩個大坑

**坑一：遇到 .5 不是一律進位。** Python 3 的 `round` 使用「**銀行家捨入法**」(round half to even)：剛好在中間時，捨入到**偶數**那一邊。

```python
print(round(0.5), round(1.5), round(2.5), round(3.5))   # 0 2 2 4
```

為什麼要這樣？因為「一律進位」在大量資料平均之後會**整體偏高**；捨入到偶數則一半往上、一半往下，長期下來誤差互相抵消。這是統計和金融界的慣例，但和你國小學的「四捨五入」不同。

**坑二：浮點數本身就不準。**

```python
print(round(2.675, 2))          # 2.67！不是 2.68
print(f"{2.675:.20f}")          # 因為 2.675 實際上存成 2.67499999…
```

如果真的要「國小那種四捨五入」，請用 `Decimal`：

```python
from decimal import Decimal, ROUND_HALF_UP
x = Decimal("2.675")
print(x.quantize(Decimal("0.01"), rounding=ROUND_HALF_UP))   # 2.68
print(Decimal("2.5").quantize(Decimal("1"), rounding=ROUND_HALF_UP))   # 3
print(Decimal("-2.5").quantize(Decimal("1"), rounding=ROUND_HALF_UP))  # -3（遠離 0）
```

### 3.5 布林值其實是整數

`True` 和 `False` 是 `int` 的子類別，數值分別是 1 和 0。這讓「計數」變得很方便，但也是一個要小心的地方（單元四的練習題會考）。

```python
print(True + True, True * 10)        # 2 10
print(isinstance(True, int))         # True
scores = [90, 45, 70, 30, 88]
print("及格人數：", sum(s >= 60 for s in scores))   # 每個比較結果是 True/False，加起來就是個數
```

## 4. 字串：不可變的字元序列

### 4.1 索引和切片：把索引想成「刀口」

字串可以用 `s[i]` 取出單一字元，用 `s[start:stop:step]` 切出一段。切片規則一句話：**包含開頭、不包含結尾**。

最好記的方法是把索引想成「字元之間的刀口」：

```text
   +---+---+---+---+---+---+
   | P | y | t | h | o | n |
   +---+---+---+---+---+---+
   0   1   2   3   4   5   6      ← 正向刀口
  -6  -5  -4  -3  -2  -1          ← 反向刀口
```

`s[1:4]` 就是「在刀口 1 和刀口 4 之間切下來」，得到 `yth`。

```python
s = "Python"
print(s[0], s[-1])        # P n：第一個、最後一個
print(s[1:4])             # yth
print(s[:2], s[2:])       # Py thon：省略代表「從頭」或「到尾」
print(s[::2])             # Pto：每隔一個取一個
print(s[::-1])            # nohtyP：step 為負 → 反過來走 → 反轉字串
print(s[-3:])             # hon：最後三個字元
```

**切片超出範圍不會報錯**（會自動截斷），但**單一索引超出範圍會報錯**：

```python
s = "Python"
print(repr(s[10:20]), repr(s[-100:2]))   # '' 'Py'
try:
    s[10]
except IndexError as e:
    print("IndexError:", e)
```

### 4.2 常用方法（全部都回傳「新字串」）

字串不可變，所以下面這些方法都**不會改到原本的字串**，而是回傳一個新的：

```python
s = "  Hello, World!  "
print(repr(s.strip()))          # 去掉頭尾空白
print(repr(s.lower()), repr(s.upper()))
print(s.replace("l", "L"))      # 全部取代
print(s.replace("l", "L", 1))   # 只取代第一個
print(s)                        # 原本的 s 完全沒變！
s = s.strip()                   # 要「改」就得重新指派
print(repr(s))
```

`split()` 有一個很多人不知道的細節：**有沒有給分隔符號，行為完全不同**。

```python
print("a,b,,c".split(","))        # ['a', 'b', '', 'c'] ← 指定分隔符號：兩個逗號中間會有空字串
print("  a  b   c ".split())      # ['a', 'b', 'c']     ← 不指定：任意空白都算，而且丟掉空字串
print("  a  b   c ".split(" "))   # ['', '', 'a', '', 'b', '', '', 'c', ''] ← 指定空白：很亂
```

> 💡 讀取「空白分隔的數字」時，**永遠用不帶參數的 `split()`**，它能處理多個空白、頭尾空白、tab 等各種情況。

```python
words = ["2024", "01", "05"]
print("-".join(words))            # 用 "-" 把串列接起來 → 2024-01-05
print("data.csv".endswith((".csv", ".tsv")))   # 可以一次檢查多種結尾
print("abc123".isalnum(), "123".isdigit(), "中文".isalpha())   # 中文字也算字母！
```

> ⚠️ **效能陷阱**：在迴圈裡用 `s += 字元` 一個一個接字串很慢。因為字串不可變，每次 `+=` 都要建立一個新字串並複製全部內容，總共是 O(n²)。正確做法是先放進串列，最後一次 `"".join(...)`。

### 4.3 f-string：格式化輸出的瑞士刀

在字串前面加 `f`，就可以在 `{}` 裡放任何運算式：

```python
name, age = "小明", 18
print(f"{name} 今年 {age} 歲，明年 {age + 1} 歲")
```

`{}` 裡還可以加上冒號 `:` 和「格式規格」，控制數字的顯示方式：

| 寫法 | 意思 | 範例 | 結果 |
|---|---|---|---|
| `:.2f` | 小數點後 2 位 | `f"{3.14159:.2f}"` | `3.14` |
| `:10` | 寬度 10（數字預設靠右） | `f"{42:10}"` | `        42` |
| `:<10` `:>10` `:^10` | 靠左、靠右、置中 | `f"{'hi':^6}"` | `  hi  ` |
| `:*^10` | 用 `*` 填滿 | `f"{'hi':*^6}"` | `**hi**` |
| `:05d` | 補 0 到 5 位 | `f"{42:05d}"` | `00042` |
| `:,` | 千分位 | `f"{1234567:,}"` | `1,234,567` |
| `:.1%` | 百分比 | `f"{0.256:.1%}"` | `25.6%` |
| `:b` `:x` `:o` | 二、十六、八進位 | `f"{255:x}"` | `ff` |
| `!r` | 用 `repr()` 顯示（字串會有引號） | `f"{'a'!r}"` | `'a'` |
| `=` | 連運算式一起印出（除錯神器） | `f"{x=}"` | `x=5` |

```python
pi = 3.14159265
price = 1234567.891
print(f"|{pi:.2f}|{pi:10.3f}|{pi:<10.1f}|")
print(f"|{price:,.2f}|{price:>15,.0f}|")
print(f"|{7:03d}|{255:b}|{255:x}|{0.075:.1%}|")
width = 8
print(f"|{'置中':^{width}}|")     # 格式規格裡也可以放變數
x = 10
print(f"{x * 2 = }")
```

> ⚠️ `f"{-0.04:.1f}"` 會得到 `"-0.0"`。如果題目要求不能輸出負零，要另外處理（單元一第一題就會遇到）。

## 5. 讀取輸入：`input()` 永遠回傳字串

做練習題時，資料會從「標準輸入 (stdin)」給你。`input()` 每次讀**一行**，而且**回傳的一定是字串**，數字要自己轉。

```python
# 在練習場或練習題中，平台會提供 stdin。這裡用字串模擬讀進來的一行：
line = "3 5 7"
a, b, c = map(int, line.split())    # split 切開 → map(int, ...) 把每一個轉成整數 → 拆給 a, b, c
print(a + b + c)

nums = [int(x) for x in "10 20 30".split()]   # 不知道有幾個數字時，用串列
print(nums, sum(nums))
```

| 輸入格式 | 讀法 |
|---|---|
| 一行一個整數 | `n = int(input())` |
| 一行多個整數 | `a, b = map(int, input().split())` |
| 一行很多個、數量不定 | `nums = list(map(int, input().split()))` |
| 先給 n，接著 n 行 | `n = int(input())`，再 `for _ in range(n): ...` |
| 不知道有幾行，讀到結束 | `import sys` 再 `data = sys.stdin.read()` |

```python
import sys
data = sys.stdin.read()          # 一次讀完全部（這裡沒有輸入，所以是空字串）
print(repr(data), data.split())
```

> 💡 讀到沒有資料時，`input()` 會丟出 `EOFError`。如果題目說「讀到輸入結束為止」，可以用 `try/except EOFError`，或直接用 `sys.stdin.read()`。

## 6. 本章小結

| 觀念 | 一句話記住 |
|---|---|
| 變數 | 是貼在物件上的標籤，`b = a` 不會複製 |
| 可變性 | list/dict/set 可以原地改；int/str/tuple 不行，「改」其實是做一個新的 |
| `is` vs `==` | 比值用 `==`；只有比 `None` 才用 `is` |
| 整數 | 沒有上限，但超過 4300 位的 `int(str)` 會出錯 |
| `//` 和 `%` | 往負無限大取整；餘數和除數同號 |
| 浮點數 | 有誤差；比較用 `math.isclose`，算錢用 `Decimal("...")` |
| `round` | 銀行家捨入，而且受浮點誤差影響 |
| 字串 | 不可變；方法都回傳新字串；`split()` 不帶參數最好用 |
| `input()` | 永遠回傳字串 |

### 常見錯誤速查

1. `a = b = []` 讓兩個名稱指向**同一個** list，改一個兩個都變。
2. `"5" + 3` 會 `TypeError`：Python 不會自動幫你轉型（這叫「強型別」）。
3. `if x == None` 能動但不好，請寫 `if x is None`。
4. `f"{-0.04:.1f}"` 是 `"-0.0"`。
5. 在迴圈中 `s += ...` 串接大量字串很慢，請用 `"".join(...)`。
